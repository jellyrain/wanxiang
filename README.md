# 万象工坊

万象工坊是一款面向小说、原创角色（OC）与世界观创作的本地资料管理工具。

把人物、设定、故事发生的地点，以及真正写下来的章节放在一起。围绕作品整理资料，通过关系、地图和年表梳理故事，让设定与正文可以相互查找、持续完善。

## 可以做什么

### 整理作品与世界

管理多部作品，为每部作品建立独立世界，也可以让同一世界下的作品共用设定。章节和创作计划归属各自作品，人物与世界资料可以跨作品复用。

### 建立人物档案

记录人物简介、经历、补充资料和标签，分别管理人物特写与设定参考图。支持多重身份、不同形态和成长阶段，保留人物在不同时期的状态。

### 完善故事设定

- **世界档案**：整理规则、制度、组织与其他通用设定。
- **物品库**：管理装备、道具的定义，在角色页关联物品并记录持有数量与状态。
- **功法库**：记录功法内容，在角色页关联功法并维护修习进度。
- **地点库**：整理场景与地点资料，由角色、地图标记或世界条目选择关联。
- **资料配置**：按人物、物品、功法、地点分别配置数值默认模板和补充字段。物品类别、功法流派、地点类型可自行新增、改名、排序、停用或删除，初始选项也一样；删除使用中的类别时可转移资料或清空类别。

标签用于多选筛选，补充资料用于填写有名称的文字内容。编辑中可直接新增标签、类别和数值模板，当前输入会保留。物品、功法和地点按“基础资料、详细设定、图片”编辑。

### 梳理关系与事件

用关系图谱查看人物联系，用地图组织地点，用年表记录事件。关联的资料可以直接跳转查看，也可以返回来源页面继续查看。

角色页的“物品、功法与地点”和世界条目页提供关联入口；地图标记保存后可关联地点库资料。三库编辑页专注资料本身，详情页保留已有引用的查看入口。

### 写作与阅读

管理分卷、章节、大纲和创作计划。正文支持 Markdown 阅读与预览。未保存章节会暂存到当前设备，重新进入后可继续草稿；资料或目录已有变化时，旧草稿仅供核对合并。

全局搜索可选择当前世界或全部世界；图鉴搜索涵盖标签、补充资料和正文，并可按补充字段筛选、排序。常用筛选和视图在本次会话内保留。地图设置、剧情节点和标记可以直接保存整张地图，也可先暂存到画布。

### 保存创作过程

素材库集中管理图片及其说明、标签和引用。通过修改历史、备份与恢复、资料导入导出，保留创作过程中的不同版本，也方便迁移已有资料。

## 本地使用，也能连接 AI

创作资料保存在本机。桌面程序运行时，可以通过浏览器访问资料库，也可以使用 HTTP API 或 MCP 连接 AI 工具，辅助读取、整理和维护创作内容。

## 获取应用

- [Releases](https://github.com/jellyrain/wanxiang/releases)：下载正式版本，查看各版本更新说明。
- [Actions](https://github.com/jellyrain/wanxiang/actions/workflows/desktop-release.yml)：获取最新构建的测试包，在成功任务的 **Artifacts** 中选择对应平台。

打开应用后，可以从新建作品开始，也可以导入已有资料，再逐步补充人物、世界设定和章节。
