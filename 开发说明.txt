万象工坊 · 人物图鉴、身份、形态、阶段、关系图谱、世界档案、地图探索、历史年表与剧情章节。

已确定：Windows、macOS、Linux 桌面应用；React + TypeScript；Radix UI Primitives；React Flow；SQLite；沿用原 Demo 视觉布局。三端构建与 GitHub 发布见 docs/GitHub三端发布指南.md。
产品名字：万象工坊。工程目录和 package.json 包名统一为 wanxiang。
软件初版图标：public/brand/app-icon-v1.png；黑长直手绘女孩、浅灰白背景。

依赖和环境由用户安装。使用 pnpm；开发过程不自动安装依赖、下载运行文件或安装环境。
当前电脑已有 Node.js 24 和 pnpm 11，无需重复安装。

请在 PowerShell 中执行：
Set-Location -LiteralPath 'F:\project\wanxiang'
pnpm install
pnpm exec install-electron

安装完成后：
pnpm dev            启动开发版桌面窗口
pnpm typecheck      检查 TypeScript
pnpm test           使用临时数据库验证内容保存规则
pnpm build          编译桌面程序和界面
pnpm start          打开编译后的桌面程序

开发资料保存在本工程 .local-data，不读取或覆盖旧 Demo 的浏览器副本及旧技术样例数据库。
首次运行从现有 Demo 导入两份人物基础档案及原图。待定内容维持待定。
打包使用 electron-builder，同时生成可选安装位置的 NSIS 安装版与文件夹 ZIP 免安装版；两者已接入软件内更新和升级前资料保护。本次首次打包由用户授权完成，成品在 release\windows，验收详情见 安装与升级说明.txt。已提供本机 HTTP API、浏览器编辑和配套 Skill。
人物关系图谱、世界档案、地图探索、历史年表与剧情章节已接入，其他模块按功能逐项开发。

使用形式与窗口
启动桌面软件后，HTTP 服务自动启动。软件设置 → 浏览器与 AI 连接，显示实际地址并可在浏览器打开。
默认浏览器地址为 http://127.0.0.1:43127；端口占用时自动换号，以软件显示为准。浏览器与桌面读写同一份资料。
5173 仅供 Electron 界面热更新。pnpm dev 启动时也构建浏览器页面，改源码后重新构建或重启 dev 才更新该页面。
默认窗口为 1440×810（16:9），工作区较小时等比缩小，手动拉伸窗口保持比例。最大化使用系统工作区。
顶部使用与界面统一的自定义标题栏，支持拖动，右上角保留最小化、最大化/还原和关闭。
开发期间启动的是 Electron 运行程序；可执行文件名称和 Windows 软件信息在安装包阶段配置。

界面密度与统一控件
图鉴使用自动分栏的小卡片，默认窗口约每行 4 张；只有两个人物时保持卡片宽度，不再撑满两列。
全部下拉框使用 Radix Select，勾选框使用 Radix Checkbox，菜单按四种主题显示。
文字和数字输入、文本域通过 Fields.tsx 统一封装；Radix Primitives 不提供单独的普通文本输入组件。
输入和下拉框去掉金色焦点外圈，聚焦只轻微调整边框；键盘操作仍有可见的焦点提示。
图谱在当前窗口内铺满可用空间，缩放控件完整显示；人物改用紧凑横向节点。
人物详情与关系清单按需展开，可收起侧栏或展开画布；切换视野时自动适配节点位置。

本次可用功能
人物列表与档案查看、按姓名/称号/化名/身份/组织/标签搜索、图鉴/列表视图切换。
新建/编辑姓名、称号、状态、题记、简介、人物经历、基础能力与待定内容。
人物标签提前配置：在角色图鉴点击“配置标签”，创建、改名、设置颜色或删除标签。
标签库按世界保存，未使用的标签也保留；人物编辑时多选已有标签。
改名或修改颜色会同步所有关联人物；删除前显示关联数量并确认，人物资料保留。
自定义文字字段；选择并保存 PNG/JPEG/WebP 人物图片。
图鉴卡片、列表、档案和图片预览统一展示人物特写；原有拼图默认只取最左侧特写。
编辑档案可选择“单人图片”或“左侧特写”，用滑块微调取景宽度；原始图片不改写。
右上角“主题”切换墨金、月白、深海、暮紫，页面、编辑弹窗及标题栏同步，重启保留选择。
人物归档与恢复。修改有版本校验，并保留底层历史记录。
人物阶段已接入；版本历史的浏览与回退界面仍待后续接入。

人物属性模板
角色图鉴 → 属性模板：创建、复制、改名或设置新角色的默认模板。
每套模板可配置 1 至 60 个维度，调整名称、顺序、最小值、最大值和单位。
已保存的维度可停用、恢复，原有数值会保留；新建但尚未保存的维度可以移除。
编辑档案 → 人物属性：选择模板并填写数值。留空表示未定，0 是实际数值。
角色档案 → 属性：3 至 10 维显示雷达图，其余维数显示属性条，按每维自身范围展示。
切换模板或暂不使用模板，会保留各套模板下已填写的数值。
模板改名、重排、停用和范围调整会同步关联档案；缩小范围保留超界旧值并提示，不自动改写。
默认模板只影响之后新建的角色；已有角色保持原选择。初始角色不填入示例能力数值。

人物身份、形态与阶段
角色档案 → 身份：新增或编辑公开身份、隐藏身份、化名、称号、组织与说明。
同一人物可同时拥有多个身份；停用后保留，仍能通过化名搜索。阶段中的旧化名也可搜到本体人物。
角色档案 → 形态：为同一人物添加形态，分别记录外观、变化条件、代价与限制。
图片、能力、属性可分别共用基础档案或独立配置；独立属性可以使用不同模板。
形态可设为默认、停用或恢复；图鉴卡片采用默认形态图片，档案左侧缩略图切换当前形态。
基础能力在“编辑基础档案 → 人物经历”中填写。
角色档案顶部 → 记录阶段：填写名称和时间/章节，选择当时身份、可用形态及默认展示形态。
每个阶段保存当时的基础资料、图片、标签、身份、形态、能力、数值和使用的属性模板定义。
阶段栏切换时期，缩略图切换该时期的形态。阶段内可以独立填写各形态的属性数值。
后续基础档案、标签或模板修改，不自动改变已记录阶段。
修订阶段默认保留原副本；明确勾选“重新取当前基础资料、身份与形态”后才重建记录。
阶段编辑新增的身份/形态从当前资料取得；已有条目保留当时资料。
“阶段”页可调整顺序、归档和恢复记录。身份最多 60 个，额外形态最多 40 个，阶段最多 100 个。
当前没有自动推算身份与形态组合，也没有把独立角色转成另一个人物的形态。小说设定由用户填写。

人物关系图谱
左侧“关系图谱”进入当前世界的人物图谱；人物档案“关系”页也可定位对应记录。
先配置关系类型的名称与颜色，再通过“添加关系”或人物两侧连接点拖线建立联系。
支持单向和双向关系、自定义关系名称、说明、待定/已确认状态；同一对人物可以记录多种联系。
双方分别关联自己的阶段，也可选择通用关系；按人物和阶段筛选时，同时显示该阶段与通用关系。
关系记录独立保存，不修改已经记录的人物阶段快照；各身份与形态归于同一个本体人物节点。
按类型、人物、阶段、姓名/化名和关系内容筛选；待定关系以虚线显示，可隐藏待定或显示已归档记录。
拖动节点自动保存位置，支持缩放、显示全部节点和整理布局；切换筛选保留未显示节点的位置。
关系可归档与恢复；类型可停用与恢复，停用不会丢失旧关系。修改类型同步图谱并保留历史。
更新冲突会提示重新读取；布局保存失败可重试，或确认后载入已保存布局。
当前只实现人物之间的关系；地点、组织、器物等节点随对应模块接入。不会从旧 Demo 导入虚构的示例关系。

数据接口说明
CharacterInput 使用 tagIds 关联已配置标签，人物保存不会隐式创建标签。
saveTag / deleteTag 管理标签库；标签变更同时更新关联人物版本及历史，防止旧编辑覆盖新标签。
portraitWidth 保存从左边取景的宽度百分比，范围 15–100；主题存入资料库 meta 的 ui-theme。
旧库启动时迁移已有标签并保留编号，仅对原始导入图片默认启用特写，已更换的图片保持原取景。
saveAttributeTemplate 管理当前世界的模板；CharacterInput.attributes 以模板编号、维度编号保存数值和模板版本。
省略 attributes 时保留原属性；新人物省略该字段时采用当前默认模板，显式 templateId:null 表示暂不使用。
属性历史同时记录当时使用的模板定义；结构变更递增关联人物版本，拒绝旧草稿覆盖。

人物扩展接口（当前通过 Electron IPC，尚未开放 HTTP API）
saveCharacterVariants 更新身份或形态，可只传一个列表；已有条目以停用代替删除。
saveCharacterStage 创建或修订阶段；只有 recapture:true 明确重建当时资料，attributeValues 只影响该阶段。
reorderCharacterStages 调整完整阶段顺序。所有写入均检查所属人物、expectedVersion 并在事务中保存历史。
独立形态引用的模板变动也会递增人物版本；冻结阶段沿用自己的旧模板定义。
旧库升级为现有人物加入空身份/形态/阶段，不自动生成小说设定。

关系扩展接口（当前通过 Electron IPC）
saveRelationType 配置当前世界的类型，重命名/颜色/启停变更同步递增关联关系版本并保存历史。
saveRelation 创建或编辑两个人物之间的关系，检查 expectedVersion、expectedTypeVersion、所属世界及双方阶段。
archiveRelation 归档/恢复记录；恢复前检查同名同类重复关系。
saveGraphLayout 按人物编号合并位置变更，使用 expectedVersion 防止过期布局覆盖，并保留隐藏节点位置。

世界档案
左侧“世界档案”进入当前世界的设定库，分类与条目按世界保存；同一世界的多部作品可共用资料。
先“配置分类”，自定义名称、颜色与说明，可停用或恢复；停用不丢资料，已有条目仍可编辑。
新建/编辑条目的名称、别名、摘要、完整正文、待讨论内容和来源说明；状态为草稿、待讨论或已采用。
每个条目可添加最多 60 项自定义文字字段；留空与填写 0 分别保留。
支持关联 PNG/JPEG/WebP 图片，列表展示缩略图，阅读页可打开完整图片，原图不改写。
条目可以关联同一世界的人物和其他设定，注明关联说明；按固定编号引用，改名后仍可跳转。
阅读页显示“关联档案”和“引用此条目”；人物档案新增“设定”页签，反向列出引用这个人物的条目。
人物关联属于本体人物，不改变已经记录的阶段；当前世界条目尚未加入 React Flow 图谱。
支持按分类、状态、名称/别名/正文/字段内容检索，归档和恢复条目；已有归档关联保留并标识。
分类与条目均有版本校验和事务历史；分类更新会递增关联条目版本，阻止过期编辑覆盖。
升级只新增空设定库，不把 Demo 的示例世界内容自动写为小说正史。当前未实现设定历史的浏览与回退界面。

世界档案接口（当前通过 Electron IPC）
saveWorldCategory / saveWorldEntry / archiveWorldEntry 管理分类、内容、关联与归档。
WorldEntryInput 检查 expectedVersion 和 expectedCategoryVersion，以及分类、图片、引用目标的所属世界。
pickWorldImage 选择本地图片，使用已有媒体保存机制；所有输入保留长度、编号和状态校验。

地图探索
左侧“地图探索”创建当前世界的地图，支持一世界多地图；地图不自动写入小说设定。
可在软件内直接绘制陆地、森林、山脉、河流和路线，也可选择已有 PNG/JPEG/WebP 图片作为底图。
浏览工具支持拖动画布、拖动地点，提供缩放、适配完整地图和展开画布；擦除工具点击移除一笔地形。
地点工具点击地图新增标记，可编辑名称、自由填写类别、说明、坐标、图片、收藏状态及解锁节点。
地点可关联当前世界的人物和世界设定，阅读时点击跳转；原有已归档关联保留并标识。
作者全貌展示全部地点；探索视图按剧情节点显示已知资料，未解锁地点只显示匿名锁定标记。
搜索、类别与收藏筛选仅使用已显示资料，避免从筛选结果泄露尚未解锁地点。地形本身不做战争迷雾遮罩。
剧情节点可添加、改名、调整顺序；地点通过固定编号关联节点，改名不会丢失归属，被使用的节点不能直接移除。
地图剧情节点独立配置；年表事件可关联节点并跳转到对应探索视图。尚未与剧情章节自动联动，也不替代人物阶段记录。
地图支持归档与恢复，地点以归档代替直接删除；归档地图可以浏览，恢复后才能编辑。
所有地图修改先进入草稿，点击“保存地图”统一保存；支持本轮编辑最近 20 步撤销/重做，保存后清空撤销栈。
切换模块、切换地图或关闭窗口时，对未保存修改给出提醒；设置和地点弹窗也有未保存保护。

地图接口（当前通过 Electron IPC）
saveMap / archiveMap / pickMapImage 管理地图整体、归档和本地图片。
WorldMapInput 使用 expectedVersion 防止旧草稿覆盖；地形、节点、地点及历史在同一事务中保存。
校验图片、人物与设定所属世界，以及合法坐标、节点编号和引用；单张地图最多 100 个节点、500 个地点、1000 笔地形，总计 50000 个地形采样点。
旧库仅新增 world_maps 和 map_history 空表，不更改已有小说资料。

历史年表
左侧“历史年表”管理当前世界的事件。一世界可以创建多份年表，分别记录前史、作品主线或人物经历。
支持新建年表、修改名称和说明、归档恢复。时代可新增、改名、填写说明、上移下移；已有关联事件的时代不能直接移除。
事件填写名称、时代、发生时间、结束时间、摘要、详细经过与影响，以及草稿 / 待定 / 已确认状态。
时间为自由文字，支持自定义年号、相对时间和留空；当前不解析历法、不自动计算日期或按日期排序。
年表按时代顺序、同一时代内的事件顺序展示；使用事件卡片旁的箭头调整先后，排序立即保存。隐藏归档事件时跳过这些记录，关键词/人物/状态筛选中暂不提供排序。
事件可关联本体人物或具体阶段、世界设定、地图地点，以及每张地图在此时对应的剧情节点。
点击人物关联可打开当时阶段；人物档案新增“事件”页签，按当前人物阶段列出相关事件，并可反向定位年表。
地点关联打开作者全貌并选中地点；“此时的地图”打开指定地图节点的探索视图。所有关联以固定编号保存，改名后仍有效。
年表不会重写人物快照或地图进度；地图节点被事件引用后不能直接删除，即使事件或年表已经归档，也需先解除关联。
已有已归档引用保留并标识，不能为新事件直接添加归档档案；事件以归档代替移除。
支持搜索事件名称、时间、正文、参与人物姓名和地点名称，按时代、人物、确认状态筛选，切换包含归档。
编辑弹窗中点击保存才写入；关闭编辑时提醒未保存内容，关闭软件也会保护打开的年表编辑。

本机 HTTP API 与浏览器（2026-10-26）
启动软件自动提供浏览器读写、原图读取、图片上传，以及所有内容保存操作；退出软件服务随之关闭。默认绑定 127.0.0.1；桌面可开启局域网模式监听 0.0.0.0。
本机浏览器自动建立同源 HttpOnly 会话，其他设备按桌面设置直接进入或使用临时密码登录，可记住设备 30 天。PowerShell Skill 使用每次启动生成、仅能从回环地址使用的 Bearer 令牌。新用户的连接文件默认位于 %APPDATA%\wanxiang\connection.json；检测到旧 %APPDATA%\oc-studio 目录时继续沿用旧目录，包含实际端口和令牌，不要公开或提交这个文件。
GET /api/v1/snapshot 返回完整资料；GET /api/v1/schema 返回全部内容操作签名与 TypeScript 字段定义。POST /api/v1/commands/{操作名} 接收 {args:[参数...]}。
POST /api/v1/assets?worldId={编号}&name={文件名} 接收原始图片字节。只允许 PNG/JPEG/WebP，单张不超过 25 MiB，同世界内重复图片去重。
浏览器和桌面每两秒检查更新标识；编辑中的草稿不会被后台刷新覆盖，保存仍执行版本检查。遇到冲突需要重新读取和合并。
配套 Skill 源码：skills/wanxiang-workshop。PowerShell 辅助脚本无需 Node.js 或 Python，已验证 Windows PowerShell 5.1。输入契约由 scripts/build-api-contract.mjs 在构建时生成。
隔离测试可指定 WANXIANG_DATA_DIR、WANXIANG_CONNECTION_FILE 和 WANXIANG_HTTP_PORT；并行桌面测试还应设置独立 WANXIANG_USER_DATA_DIR 以隔离 Electron 单实例锁与浏览器存储。WANXIANG_DEV_URL 指定开发页面。旧 OC_STUDIO_ 前缀仍可读取，同名新变量优先。不要将测试连接写到正式连接文件。Windows appId 保持原值，仅用于安装升级身份兼容，与项目目录、包名无关。

局域网与 MCP（2026-10-26）
连接模式可即时切换，先等待进行中的请求结束再切换监听；端口保持原值。其他设备使用面板显示的实际 IPv4 地址，不使用 0.0.0.0 作为浏览器地址。
浏览器访问可选「可信局域网直接访问」或「密码保护 · 临时密码」。直接访问自动进入；密码模式使用软件生成的 8 位临时密码，5 分钟有效、仅一次使用、10 次错误后失效。HTTP 不加密。不自动修改防火墙，不开放公网穿透。
密码模式可勾选「记住这台设备」，独立设备凭证保留 30 天，跨软件重启有效。不勾选时会话最长 24 小时，软件重启后需重新登录。重新生成临时密码不撤销旧登录；「清除登录设备」或切换访问方式会撤销旧登录。关闭局域网停止远程访问，已记住设备仍可在重新开启后、有效期内使用。
临时密码与未记住的登录只存内存；记住登录仅保存凭证的 SHA-256 摘要和期限，不保存密码或原始登录凭证。旧版已开启局域网的配置升级后保留密码保护，原 MCP 密钥不变。
MCP 地址为实际服务地址加 /mcp，使用官方 @modelcontextprotocol/sdk 1.32.2 和 zod 4，无状态 Streamable HTTP、JSON 响应；协议协商、工具发现、参数校验和协议错误由 SDK 处理。GET/DELETE 返回 405，不提供 SSE 推送、旧 SSE 传输、stdio 或 OAuth 自动登录。
桌面可查看和复制 MCP URL 与 Authorization 请求头；MCP 密钥独立持久化到数据目录 connection-settings.json，不进入创作备份。该文件含密钥，不要分享或提交。更换 MCP 密钥仅撤销旧 AI 密钥，浏览器登录不受影响；清除浏览器登录也不改变 MCP 密钥。直接访问模式下 MCP 仍需密钥。
MCP 工具：read_library、describe_operations、call_operation、import_image。内容与备份操作复用原接口校验；连接设置和密钥管理仅开放给桌面 IPC。
开发依赖由用户通过 pnpm 安装，SDK 随应用运行，无需另起 MCP 服务或安装额外运行环境。配套 Skill 的 references/mcp.md 提供调用约定；不同 MCP 客户端的配置外壳可能不同，须支持 Streamable HTTP 与自定义认证请求头。

默认自动备份关闭。首次基准必须手动预览范围与大小，再点击“手动建立全量基准”。自动任务只写新增、更新、删除记录，绝不自动首备、全量重基准或全量合并。
数据库触发器与内容保存同事务写入行级日志；覆盖桌面、网页和 API。现阶段是记录级增量，修改正文会保存该记录的完整新正文，并保留必要历史记录，不复制整个数据库。
图片以 SHA-256 去重；已有相同图片不再复制。没有内容变化就跳过，文件写入和校验完成后才推进游标；失败重试从上次成功位置继续。
备份目录包含 repository.json、points/<编号>/records.json 与 manifest.json、objects/<内容哈希>。manifest 是完整恢复点的提交标记，残留的未完成尝试不算恢复点。
恢复先校验依赖链、记录、图片、数据库结构和关联，在临时数据库重建；通过后在原库中以单一事务切换内容。失败回滚原库，恢复过程中暂停 UI/网页/API 写入。
有可用基准时，恢复前自动补存尚未备份的增量；无基准不自动全量保护当前库，预览明确提示影响。恢复预览为单次 token，十分钟有效，预览后有新保存需重新预览。
恢复后保留原分支，新的修改从所选恢复点延伸为新的增量分支。现存恢复点依赖和当前链头禁止单独删除；过期清理保留所需祖先，图片仅在没有恢复点引用时清理。
LibrarySnapshot 增加 generation。所有内容命令支持请求体 generation，上传使用 X-Wanxiang-Generation；恢复后必须提供正确代次，旧代次返回 RESTORED。桌面与网页自动携带，未编辑页面重载，旧草稿保留并阻止覆盖。
备份 API 与桌面使用相同服务，schema 含 getBackupStatus、saveBackupSettings、estimateBackup、createBackupBaseline、runIncrementalBackup、previewBackupRestore、restoreBackup、deleteBackupPoint。
Skill 增加 -Generation 参数及备份说明。恢复之后 AI 必须重新读取资料、核对原请求，不允许仅换代次盲发旧草稿。
当前恢复格式仅支持相同资料结构；不兼容时保留备份并拒绝恢复。结构更新后自动增量停止，需要用户手动新建基准；具体安装升级流程留在安装包阶段接入。
关闭软件会停止自动备份；退出时等待正在执行的备份/恢复结束。不包含系统后台常驻、云同步、跨版本迁移、逐字段回退与完整导入导出。
